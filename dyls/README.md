# 电影猎手统一清理与播放增强

用户提供的 `dyls1.mbxqnb.cn/api/v1/movie/index_recommend` JSON 抓包包含 6 条轮播广告和 10 个广告图标。成功响应必须同时符合 `msg: 获取成功` 与 `data` 数组结构。

仅移除 `data` 中 `layout: advert_self` 的区块，并在 `index_recommend_carousel` 的 `list` 中过滤数值 `type: 3`。普通影片区块即使存在 type=3 也保留，未知卡片类型保留。播放地址、影片列表、分类跳转、字幕与分页等非广告字段不修改。

共用 JSON 操作新增有结构校验的 `mapArray`，支持按区块清理内层数组。成功响应格式仅通过本模板显式配置，不改变已有网站的成功判断。

使用统一规则或本目录独立规则之一。只登记 `dyls1.mbxqnb.cn`，按用户要求覆盖 `/api/v数字/` 下的 API 路径。其他接口复用上述成功格式和广告布局时自动清理；未知结构保留，未实测其他接口。其他域名不自动扩展，不处理 HLS。用户抓包离线验证通过，手机效果仍需更新订阅并刷新缓存确认。

## 多页面 JS 广告入口

- `index-BSCFNKjP.js`：开屏配置选择器改为返回 null，开屏触发改为关闭，应用壳的广告状态本地固定为 false。旧 Redux / 存储中的广告状态不会锁定页面滚动或遮挡登录。公告、登录、播放器弹层、状态栏、路由和认证刷新保留。
- `helperService-BjnnVgxU.js`：仅替换广告 hook 与广告配置加载的导出，分别返回加载完成的空数据与 Promise；保留头部主题、通知和其他导出。阻止广告配置网络加载、旧广告缓存回退及广告图片预热链路。
- `NewAds-CtNp18Uc.js`：两个广告网格导出改为返回 null，关闭共用图标网格、加载占位和模块内广告缓存回退。确认搜索页 `search_input_under` 与播放页 `player_episode_up` 使用此模块；其他页面使用该模块时也生效。

仅匹配该精确域名已登记的 JS 文件族，全部源码指纹及替换次数必须正确；未知版本不进行部分修改。接口加密数据无需在统一脚本中解密。

## 定向缓存更新与广告空白

`sw.js` 为 index、helperService、NewAds、home、explorer、Main、search、playerService、player 文件族增加同源网络优先策略，成功 JS 缓存供离线回退。激活时仅删除这些模块旧缓存，不清空账户、历史、普通脚本、样式、影片封面或页面缓存。入口注册带独立版本参数并检查 worker 更新。旧 worker 必须先更新并激活；已有页面一直命中旧缓存时，需要重新打开页面等待更新，不能保证首次刷新立即生效。

首页推广轮播及 advert_self、筛选/排行/周表、搜索输入页、搜索结果页、播放选集上方的广告外层容器一起剔除，消除专用占位与间距。保留普通影片内容、公告、搜索、分页和播放器提示。

## 选线和续播

- 每轮自动探测最多 3 条备用线路；每次明确操作重置前最多自动换线 3 次，避免失败循环。手动切线、切集、刷新与新影片加载重置预算。
- 原有线路评分随时间按 14 天半衰期衰减；最近失败且尚未随后成功的线路降序 10 分钟，仍可手动选择。
- 自动换线携带当前进度；备用线路缺少当前集数时跳过。恢复进度上限为有效视频时长减 2 秒，防止误触发完播。沿用网站已有后台保存及请求取消机制。

完整的 10 个模块改写后通过语法、重复改写验证；缓存、探测预算、取消、续播和边界有离线行为测试。HLS 逻辑未改写。手机效果需实际更新订阅验证。
