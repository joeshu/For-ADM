# 三站结构后备适配

可可影视、网飞猫、好好看现采用“精确适配 + 结构后备”的清理流程。域名、端口和 app/数字分包的请求路径范围不变。

## 启用范围

原来的新旧版精确规则先执行，再对保留下来的代码尝试 39 种共享结构模板。后备匹配不依赖混淆变量、版本目录和文件哈希，要求真实 webpack 应用标记、业务特征、完整词法结构及一致的变量对应关系。

支持稳定的广告 getter、横幅读取、已核验混合卡片入口、播放器广告选择及动态分包缓存参数。字符串、注释、模板文本和正则中的伪代码不作为匹配对象。

2026-10-21 新增 AST 语义后备，补齐启动页直接读取配置、下载页跨函数倒计时绑定这两类缺口，见 [修复说明](MEDIA-COUNTDOWN-20261021.md)。通过真实请求 URL/方法/选项绑定识别广告配置函数，不依赖导出别名；通过局部返回引用及资源响应配对确认下载页变量。绑定不完整时仍保留精确适配结果，不猜测变量或扩大账户、公告、媒体处理范围。

HTML 的缓存参数更新新增站点品牌、应用容器及已有 app 脚本路径族校验，不再要求某个具体 app 文件名。入口和动态分包使用同一站点适配版本，vendor、样式、manifest 等资源保留。

这可处理一部分重命名和重新打包更新。业务逻辑、导出别名、框架调用、属性访问形式或广告结构发生实质变化时，仍可能需要重新适配。

## 保护与诊断

后备处理设有 2 MiB 响应大小、250,000 token 和 700 ms 软时间预算。未知语法、缺失变量、冲突、重叠及超预算时，保留精确规则处理后的响应，不提交部分后备改写。分词器随脚本本地打包且延迟初始化，不执行网站源码。

使用原有 [限时诊断](DIAGNOSTICS.md)，新增字段：

| 字段 | 含义 |
| --- | --- |
| structuralStatus=modified | 已完成结构后备改写 |
| structuralStatus=no-match | 应用源码可分析，但没有剩余支持的结构 |
| structuralStatus=not-applicable | 没有业务预筛选特征或真实 webpack 标记 |
| structuralStatus=size-limit / budget-limit | 超出大小、token 或时间预算，后备结果保留 |
| structuralStatus=rejected | 语法、绑定或候选冲突导致拒绝后备改写 |
| structuralPairs | 后备改写的源码出现位置数，与原 pairs 分开计数 |

不记录源码正文、变量名、查询参数或影片地址。手机上的预算和实际页面行为仍需设备测试。

## 自动源码检查

`KKAPP NCAT and HAPP source audit` 工作流每天 UTC 03:23 运行，也可手动触发。

当前入口与登记版本不同时，审计额外静态解析新版 webpack 加载映射，发现同源、受支持路径内的新分包并进行清理探测；不会执行网站的加载函数或业务代码。报告中的 `discovery` 记录改写、无匹配、不可验证及结构后备位置数。

当前人工核验版本及逐模块预期行为登记在 `tests/media-reviewed-sources.json`；通过需要同时满足源文件 SHA-256 和清理探测结果，不能只凭哈希或入口可访问判定通过。入口或登记分包内容变化均触发额外发现。

版本变化仍报告 `CHANGED`。发现和探测成功不会自动升级为 `PASS`、提交规则或发布适配。

## 验证记录

- 旧版 222 个相关模块和新版 744 个主脚本/动态分包，共 966 个真实 JS：清理结果与接入前一致，差异仅为预期的适配缓存版本参数。
- 将新版 744 个文件的混淆标识符统一改名、改用未知版本目录/哈希并更改应用版本号后：与独立离线模板匹配器的预期一致，共 552 个改写位置，每站 184 个，无额外改写和语法错误。
- 上述数字小于研究原型的 204 处/站，因为正式方案进一步排除了配置导出及下载相关后备模板。
- 边界测试覆盖未来入口/分包缓存参数一致性、缓存广告、卡片、getter、账户与媒体保留、错误响应、未知域名、伪代码、业务字段变化、未知导出、时间/大小限制及新分包发现。

完整源码语法和结构检查不能代替网页执行与手机实机验收。验证摘要见 `audits/media-structural-validation-20261018.json`。
