# 网飞猫 / NCAT

核验入口：`https://a.napp03.com:51111/?_c=c200000&package=napp03.com`。应用版本 2.5.29，主入口为 `app.e102418a.js` 与 `app-legacy.97e2a46b.js`。

与可可影视同系列，广告字段、专用 units 接口、广告组件、影片详情广告选择器和混合列表布局相同，但混淆变量不同。复用公共字段/JS 改写和按需列表 helper，独立登记本版本的精确代码替换。

| 广告入口 | 处理 |
|---|---|
| 主 JS `getAdvertiseById`、广告存在判断 | 返回无广告/false |
| 动态模块 `0x3e71` 的 `so` 导出 | `/v2/config/units.capi` 加载改为成功的空数组 Promise；保留公告、资源初始化等导出 |
| 共用横幅组件 | 广告数组读取返回空数组，阻止旧广告缓存回退 |
| 两组播放器模块的广告选择器 | 关闭详情 `ads` 的前贴、暂停和 native bridge 上游广告查询 |
| 入口/轮播/推荐/分类/搜索/影评瀑布流 | 在布局前过滤已确认广告类型、广告区块与带展示字段的外站推广链接，保留站内影片、分类和正常媒体 |

现代与 legacy 共 86 个改写组、72 个完整模块完成源码校验、精确差异、语法和重复执行检查。所有原始源码只用于本地核验，仓库保存最小替换片段及测试。

只登记 `a.napp03.com`，支持无显式端口的 URL 与 `:51111`；不默认扩展其他 NAPP 域名或显式端口。Quantumult X 重写正则包含端口，MITM hostname 只填写域名。其他网站的原有端口行为不变。

使用统一规则或本目录独立规则之一；更新后重新打开网页，使主 JS 和分包重新经过重写。保留账户、公告、会员/付费校验、源选择、影片地址与原有 HLS 逻辑。未做手机端实际播放与广告展示验收，不保证服务端嵌入媒体中的广告可清除。

## 手机残留反馈后的修复

首页入口读取 `text/imagePath`，轮播使用 `reco.banners.data`，影评瀑布流排版后把原条目放进 `post`。分类器现在支持文字入口、banners 根字段和 post 包装；web/browser 参数支持与路由一致的额外解码。movie/video 标签不再直接豁免推广链接，仅保留明确的正常媒体文件地址与站内影片路由。原始播放 URL 和签名不改写。

首页 HTML 仅给 app / app-legacy 入口添加 `for_adm=ncat-v3-版本`；主 JS 的动态 JS 文件名解析器添加相同版本参数，重新请求分包。版本按本站模板与公共引擎内容计算，不受瓜子或其他独立站点改动牵连。vendor、CSS、API、媒体文件、账户与浏览器其他缓存不修改。既有内存缓存完全跳过网络时，仍需退出并重新打开页面。

当前桌面浏览器只显示添加主屏幕提示，未取得手机三个页面的实际数据。因此验证范围为源码和离线行为，最终手机清理效果需更新订阅后确认。

## 网盘下载页的独立广告入口

下载页使用独立的 `units.splash/video/dhz` 广告初始化与分发，含 `ad_last_shown_time` 冷却、覆盖层、图片/视频/推广网格和倒计时。已分别适配 `8489.2643cfd8.js`、`2131-legacy.994459f5.js`：关闭初始化和分发，撤下覆盖层、归零倒计时并停止广告定时器。

原下载接口和响应不修改，保留 magnets/netdisk、文件名、大小及磁力详情跳转。CloudButton 的资源可用性、登录/评论校验及原 magnetUrl 跳转保持原字节内容；不删除真正的下载按钮，也不绕过访问校验。现共 74 个完整模块核验。新增补丁会自动更新本站主 JS/分包的定向缓存版本，需更新订阅后重新进入下载页。手机最终展示待确认。

追加下载数据入口和渲染保护：复制响应后仅清空 units.splash/video/dhz、广告类型和广告倒计时，原始响应、磁力与网盘数组不修改；广告覆盖层的渲染条件固定关闭，倒计时初始值归零。现代/legacy 均有完整源码指纹与次数校验。此保护不替代手机端实际命中核验。

首页图标入口补充精确过滤：`text` 为“精彩应用”且带点击 URL 的入口按已确认推广项剔除，包括站内应用聚合页路由；不通过外站域名判断。影片标题、普通分类和无点击 URL 的文本不按此标签删除。

## 共用清理与诊断

两站卡片清理改为构建时复用 `universal/src/shared-media-cards.js`，各自配置域名白名单；无运行时上游依赖。统一支持 post 包装、text 入口、banners 根字段和二次 URL 解码；保护站内影片和明确的媒体文件。过滤后删除原本有内容、仅因广告过滤变空的已确认 section 区块；原来就为空或结构未知的区块保留。首页轮播与区块容器按清理后的数量判断显示，加载状态不改写。

手机残留时使用 [诊断说明](../universal/DIAGNOSTICS.md)。默认无日志；开启仅持续 10 分钟。检查当前源码可运行 `node scripts/audit-media-sites.mjs`，或手动运行 GitHub Actions 的 “KKAPP and NCAT source audit”。该检查只读取入口和已登记 JS，不自动放宽域名、不改规则、不检查 HLS。
