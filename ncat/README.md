核验入口：`https://a.napp03.com:51111/?_c=c200000&package=napp03.com`。应用版本 2.5.29，主入口为 `app.e102418a.js` 与 `app-legacy.97e2a46b.js`。

与可可影视同系列，广告字段、专用 units 接口、广告组件、影片详情广告选择器和混合列表布局相同，但混淆变量不同。复用公共字段/JS 改写和按需列表 helper，独立登记本版本的精确代码替换。

| 广告入口 | 处理 |
|---|---|
| 主 JS `getAdvertiseById`、广告存在判断 | 返回无广告/false |
| 动态模块 `0x3e71` 的 `so` 导出 | `/v2/config/units.capi` 加载改为成功的空数组 Promise；保留公告、资源初始化等导出 |
| 共用横幅组件 | 广告数组读取返回空数组，阻止旧广告缓存回退 |
| 两组播放器模块的广告选择器 | 关闭详情 `ads` 的前贴、暂停和 native bridge 上游广告查询 |
| 入口/轮播/推荐/分类/搜索/影评瀑布流 | 在布局前过滤已确认广告类型、广告区块与带展示字段的外站推广链接，保留站内影片、分类和正常媒体 |

现代与 legacy 共 86 个改写组、72 个完整模块完成源码校验、精确差异、语法和重复执行检查。所有原始源码只用于本地核验，仓库保存最小替换片段及测试。

只登记 `a.napp03.com`，支持无显式端口的 URL 与 `:51111`；不默认扩展其他 NAPP 域名或显式端口。Quantumult X 重写正则包含端口，MITM hostname 只填写域名。其他网站的原有端口行为不变。

使用统一规则或本目录独立规则之一；更新后重新打开网页，使主 JS 和分包重新经过重写。保留账户、公告、会员/付费校验、源选择、影片地址与原有 HLS 逻辑。未做手机端实际播放与广告展示验收，不保证服务端嵌入媒体中的广告可清除。
