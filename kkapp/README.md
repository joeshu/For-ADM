# 可可影视

核验入口：`https://a.kkapp06.com/?_c=c1&package=kkapp06.com`，应用版本 2.5.14。HTML 只负责挂载 Vue 应用，广告由主 JS 和动态分包实现。

| 核心入口 | 处理 |
|---|---|
| `app.ef89c5cb.js` / `app-legacy.513f0edd.js` | `getAdvertiseById` 返回无广告；广告位存在判断返回 false，避免专用外层容器出现 |
| 动态模块 `0x3e71` 的 `so` 导出 | 专用 `/v2/config/units.capi` 加载函数返回 `{data:[]}` 的 Promise，启动流程继续；保留公告、资源配置及其他导出 |
| 13 组页面分包的横幅读取 | 只把 `appAdvertisements` 的广告读取替换为空数组，阻止旧缓存广告回退；一组含两种广告组件 |
| `6040` / `8796` 播放分包 | 关闭影片详情 `ads` 中的前贴与暂停广告选择器，包括 native bridge 广告查询的上游选择逻辑 |

现代和 legacy 共 46 个完整模块逐一确认指纹、替换次数、语法与重复执行。数值动态分包用文件族匹配，但每次修改须符合已核验源码；未知版本原样返回。按用户提供公告及当前发布页登记 `a.kkapp06.com`，以及 `kekys.com`、`kkys01/02/03/14/15.com` 的根域与 www。新增域名应用源码尚未全部取到，只有原源码指纹匹配才改写；不自动覆盖任意编号域名。`www.kekys.com` 当前跳转到 `dl.kkys17.com` 下载页，该下载页不按影视应用改写。

使用统一规则或本目录独立订阅之一，更新后需重新加载页面使 JS 再次经过 Quantumult X。规则不会清空账户、播放记录或浏览器全部缓存。不修改 HLS、影片线路、会员/付费校验、登录、公告或资源初始化。服务端嵌入视频中的广告不在此次范围内，手机效果仍需实际验证。
