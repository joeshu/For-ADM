# 三源影视 · 无签名 iOS App

独立于 `universal` 去广告脚本的新应用，整合可可影视、网飞猫、好好看的公开片库接口。名称暂定“三源影视”，最低 iOS 15，支持 arm64 iPhone / iPad。

## 功能

- 统一首页、站点切换、动态分类、地区/年份等筛选、搜索、详情、分集及播放线路选择。
- HTTPS 数据线路故障自动切换，支持查看检测结果、手动指定优先线路。
- 本机收藏与观看历史；支持续播、上一集/下一集和长剧集分页。iOS 默认使用系统播放器，携带原站 Referer，并每 5 秒记录进度。
- “我的 → 播放设置”可选择 0.5×、0.75×、1×、1.25×、1.5×、2× 默认倍速；播放器展示影片与集名，并支持系统画中画、AirPlay 和后台音频。退出播放器后释放音频会话。画中画及后台行为仍需真机确认。
- 播放前校验 HTTPS 地址和 HLS 清单；证书、CDN 或清单故障时自动尝试最多 5 条同集线路。只按明确的集数或片名对应切换，不使用其他集凑数。
- 选集的 `open=false` 仅表示点击时需要调用地址接口，界面不再将其标记为“需授权”；真实的账号、会员限制仍显示原站错误。
- 海报栏数可设置为自动、2、3、4 栏；选择后保存在本机。
- 18+ 分类默认隐藏；可在“我的”页面确认已满 18 周岁后开启，也可随时关闭。成人影片不进入首页推荐，关闭后也会从片单隐藏。
- 原站账户或原站访客会话；iOS 会话存入系统钥匙串，不保存密码，三站分开存储。
- 页面代码随 App 打包，不加载原站启动广告、推广横幅、网盘下载倒计时或推广脚本。当前版本不提供网盘下载入口。

本应用仍依赖原站接口，原站账号、资源权限和服务限制照常生效。仅使用服务端明确开放或播放接口授权返回的地址，不推测受限资源地址。未处理视频流内部广告。搜索和地址获取会自动建立原站访客会话；访客失效时仅自动续期一次。已登录账号不会被替换。

## 安装

产物：`dist/Sanyuan-0.2.11-unsigned.ipa`。这是**未签名**的安装包，不能直接点开安装；使用自己的合法签名方式签名后安装。没有预置证书、账号或描述文件。包标识为 `com.joeshu.sanyuan`，签名时可按工具要求调整。请使用 Xcode 构建附件中的 IPA。

0.2.11 新增发现页：上映时间轴支持年份、月份切换，Netflix、专题和排行榜接入当前片源可用的分类/专题数据；底栏扩为六项，直播和游戏入口会说明当前片源未提供目录。

0.2.10 常驻 One 风格底部导航，缓存已加载的首页和分类，离开页面时取消无用图片请求以缩短切换等待。

0.2.9 收紧首页栏目卡片与选集布局，分类筛选默认折叠次要条件并记住展开状态；播放过程中遇到线路中断时自动检查备用地址，并按同一集切换备用线路；播放器反馈加载失败与播放中断状态。线路探测只更新状态提示，避免整页重复绘制。首页栏目与合集分组使用一致的横向浏览样式。

0.2.7 参考 One 的公开界面截图重新整理主题与布局：首页、分类和片单采用浅色样式，影视详情改为沉浸深色封面与清晰的播放、收藏、简介、主演和选集分区。保留内嵌播放器及手动全屏选择，并同步切换 iOS 状态栏文字颜色。

0.2.6 首页栏目使用单行横向海报列表；“更多”按原站专题、合集或时间线入口请求完整列表并支持分页，返回时恢复栏目与列表位置。播放线路改为紧凑的横向滑动按钮。

0.2.5 加入应用内 HLS 清洗：通过仅监听本机的播放传输处理多级清单，按保守路径特征删除已知广告切片，支持在播放设置关闭。直播、加密和字节范围清单不删片；正片内嵌广告及未知特征仍可能保留。规则来源、处理边界见 [HLS 清洗说明](docs/hls-cleaning.md)。

0.2.4 优化首页推荐切换、继续观看、栏目展开；分类筛选支持点选、取消、重置、按来源与分类记忆，以及直接调整海报分栏。播放线路以卡片显示集数与选中状态，手动切换时按标题匹配同一集；找不到对应集数时提示重新选择，不使用数组位置猜测。

0.2.3 默认在详情页内嵌原生播放器，点击选集不再强制全屏；使用画面内的系统按钮切换全屏。

0.2.2 使用标准 UIScene 生命周期，关闭 chained fixups 并预留 Mach-O 头部空间，以改善现代 iOS 启动及第三方重签名兼容性。这是兼容性修正，未经手机崩溃日志确认，不能据此判断此前闪退的具体根因。

### macOS + Xcode（推荐重新构建方式）

需要 Xcode iPhoneOS SDK、Node.js 20+、npm 和 Python 3：

```sh
bash tools/build-macos.sh
```

仓库的 `Sanyuan unsigned iOS app` GitHub Actions 工作流也会使用 macOS 构建并上传 IPA 构建附件。

完成 SDK 构建后，可在 macOS 执行 `bash tools/simulator-smoke.sh`。它另行编译并签名模拟器专用程序，验证本地 WebKit 界面、原生网络桥、真实首页与海报，并实际启动 AVPlayer，等待播放时间超过 1 秒，输出首页、播放结果 JSON 和截图；分发用 IPA 始终不签名。该检查依赖原站网络可用。

该脚本使用真实 iPhoneOS SDK 编译，无需开发者证书，生成 unsigned IPA，并校验文件结构、架构及签名缺失状态。

### Linux 开发研究（不用于分发）

需要 LLVM 19 的 clang、ld64.lld 和其运行库：

```sh
npm ci
npm run build:web
python3 tools/cross-build.py --clang /path/to/clang-19 --linker /path/to/ld64.lld-19
python3 tools/check-ipa.py dist/Sanyuan-0.2.11-unsigned.ipa
```

`Sources/RuntimeSDK.h` 在 Linux 下提供本应用所需的最小公开 Objective-C ABI 声明；链接时生成仅含系统库名称与符号的 TAPI 文件，运行时链接设备上的系统框架。没有捆绑 Apple SDK，也没有模拟或替代 UIKit。macOS 编译自动使用真实 SDK 头文件。Linux 交叉编译只用于开发研究，不作为分发包。请使用 Xcode iPhoneOS SDK 产物。此前的“备用 IPA”无法保证真机兼容性，不建议继续安装。

## 验证和预览

```sh
npm ci
npm test
npm run build:web
# 若运行环境使用代理，给 Node 设置其支持的代理配置
NODE_USE_ENV_PROXY=1 npm run preview
# 另一个终端，需安装 Chromium：
NODE_USE_ENV_PROXY=1 node tools/browser-check.mjs
# 使用固定响应测试系统播放器切换及资源拒绝处理：
node tools/playback-ui-check.mjs
# 实际访问三站；--with-guest 会按原站协议创建临时访客会话
NODE_USE_ENV_PROXY=1 node tools/live-probe.mjs --with-guest
```

预览仅绑定 `127.0.0.1:4173`，本地代理用于替代原生 NSURLSession 网络桥。浏览器预览会话只保留在内存。浏览器检查脚本默认将截图写入 `/workspace/outputs`，可通过 `APP_OUTPUT` 修改目录；`CHROMIUM` 可指定浏览器路径。

`docs/live-probe.json` 和 `docs/browser-check.json` 保存验证结果，不包含用户令牌或临时签名播放地址。`docs/playback-probe.json` 记录播放 URL 的独立网络检查，浏览器界面通过不等同于视频播放通过。

## 当前限制

- 尚未进行 iPhone/iPad 真机启动、签名安装、AirPlay、后台播放及真实账号登录测试。模拟器媒体验证不代替真机验证。
- 实测“超清2”“极速蓝光”线路返回的 IP HTTPS 地址证书与主机不匹配，无法通过 TLS 校验。应用不关闭校验，会自动跳过这些线路。真实接口探针在三站均自动选择“蓝光1”并读到同集清单。接口探针不下载分片；iOS 模拟器检查另行验证真实播放。线路能否播放还取决于证书、原站授权、网络、视频编码及服务端防盗链。
- 内嵌与系统播放器均记录进度，系统播放器每 5 秒回传一次。真实播放器错误会反馈到详情页；进入历史记录本身不代表播放成功。
- 18+ 年龄确认采用用户自我声明，不是身份或年龄核验。
- 不包含离线下载、投屏管理、跨站聚合搜索、iCloud 同步或原站付费管理页面。
- 线路池、分类、图片域名由启动配置动态获取，因此不受网页 JS 文件名更新影响；签名算法、协议字段或响应加密变更时仍需要更新适配器和 App。不能承诺永久免维护。

## 文件结构与维护

- `Sources/main.m`：UIKit 容器、本地 WebKit 界面、HTTPS 网络桥、Keychain 会话、AVPlayer。
- `Web/app.mjs` / `app.css`：统一界面及交互；`app.js` 是供本地 WebKit 加载的构建产物。
- `Web/site-api.mjs`：签名、解码、路由、会话与服务端权限处理。
- `Web/sites.json`：从仓库已归档原版客户端提取的公开协议常量，含版本和源文件 SHA-256；不是用户密钥。不得在此放入账号密码或会话令牌。
- `Web/model.mjs`：影片、分类、图片与播放地址的展示模型。
- `tools/`、`tests/`：构建、IPA 校验、离线测试、真实接口和界面检查。

首次适配版本：KKAPP 2.5.16 / NCAT 2.5.31 / HAPP 2.5.24。只对已确认的影片结构进行展示；广告和未知跳转不直接渲染，从而减少网页推广组件变化对 App 的影响。

加密组件为 CryptoJS 4.2.0，按随附 `Web/vendor/LICENSE.crypto-js` 的 MIT 条款分发。开发依赖使用各自许可证。
